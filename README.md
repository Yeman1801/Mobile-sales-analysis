# **📊 Mobile Sales Analysis**

## 🔎 Project Overview

This repository contains a Jupyter Notebook (projects.ipynb) that performs exploratory data analysis (EDA) on a mobile sales dataset using Python, Pandas, NumPy, Matplotlib, and Seaborn.

The analysis focuses on:

📱 Mobile brands and pricing trends

👥 Top customers and locations

⚙️ Processor specifications and popularity

🌍 Regional pricing and delivery performance

💎 Identification of high-end devices

## 📂 Contents of Analysis

🔹 Data Exploration: dataset shape, size, columns, and summary statistics

🔹 Top 10 Expensive Mobile Brands: highest price by brand

🔹 Top 10 Customers by Quantity: most valuable customers

🔹 Processor Specification Analysis: count and comparison of processors

🔹 Price Range by Region: minimum and maximum prices in each region

🔹 Top 100 Customer Locations: locations with the highest sales volume

🔹 High-Spec Devices: mobiles with ≥ 12 GB RAM and ≥ 256 GB ROM

🔹 Average Delivery Days by Region: delivery performance comparison

## 📈 Graphs & Visualizations

📊 Bar charts → top brands, customers, and processors

📊 Region-wise comparisons → pricing and delivery days

📊 Distribution plots → price and sales quantity

📊 Highlighted tables/lists → high-end devices and top markets

## ⚙️ Requirements

Python 3.x

Jupyter Notebook

Pandas

NumPy

Matplotlib

Seaborn

OpenPyXL

Install all dependencies:

pip install jupyter pandas numpy matplotlib seaborn openpyxl

## ▶️ How to Run

Clone the repository:

git clone https://github.com/your-username/your-repo-name.git


Navigate into the project folder:

cd your-repo-name


Launch the notebook:

jupyter notebook projects.ipynb

## 🧾 Key Insights

💡 Premium brands dominate the high-price segment

💡 A few customers contribute heavily to sales

💡 Certain processors are more common in sold devices

💡 Regional differences impact both price and delivery time

💡 High-end specs (12GB+ RAM, 256GB+ ROM) are limited but important
